## Description

```
# 🎯 SPRINT GOAL – Sprint 1

Thiết lập nền tảng kỹ thuật, kiến trúc và quy trình ban đầu cho dự án Seatly - web app phục vụ tại bàn bằng QR dành cho quán ăn / quán đồ uống nhỏ đến vừa - nhằm đảm bảo backend/frontend có base source code rõ ràng, database schema và ERD được định hướng đúng với nghiệp vụ cốt lõi, UI/UX có định hướng tham khảo ban đầu và tài liệu / workflow nhóm được chuẩn hóa ngay từ Sprint đầu tiên.

### 📦 Expected Outcomes

- Backend và Frontend base source code được thiết lập ổn định trong cùng repository để làm nền cho các task tiếp theo.
- Database schema và ERD được xác định theo đúng định hướng hiện tại của Seatly: phục vụ tại bàn bằng QR, guest session, order line item, realtime tracking và vận hành cơ bản.
- Định hướng UI/UX ban đầu được xác lập cho các màn hình core như QR menu, guest entry, ordering, order tracking và giao diện staff / owner.
- Workflow tài liệu, test case và Scrum board được chuẩn hóa để hỗ trợ triển khai các Sprint tiếp theo.
```
